# Isaías Lucas · Portfólio

Portfólio pessoal em React + Vite, com direção visual inspirada na CODIK DESIGN: fundo creme, tipografia editorial e detalhes lilás.

## Projetos

- **CODIK DESIGN:** projeto em equipe com Rodrigo e Nicolas — [visitar](https://codik-design.vercel.app).
- CodeCraft, desafios web e estudos de SQL.

## Rodar localmente

```sh
npm ci
npm run dev
```

## Publicar

```sh
npm run build
```

Na Vercel: preset **Vite**, comando `npm run build`, saída `dist`.
Contato direto por e-mail, sem coleta de dados ou formulário sem integração.
